الهدف كان بناء تطبيق ويب منظم لإدارة الكورسات والمستخدمين والتسجيلات والبيانات المرتبطة بها، مع استخدام Laravel كإطار عمل لتطوير التطبيق.

عملت على تطوير أجزاء من المشروع، وتنظيم الـModels والـControllers والـRoutes والـViews، والتعامل مع قاعدة البيانات والعلاقات.

Laravel, PHP, MySQL, Blade, Eloquent ORM, HTML, CSS, Bootstrap, XAMPP, Git وGitHub.

05 — Output

تطبيق ويب يحتوي على هيكل منظم لإدارة المستخدمين والكورسات والتسجيلات، مع صفحات وواجهات مرتبطة بقاعدة البيانات.

06 — Value / Result

ساعدني المشروع على الانتقال من دراسة المفاهيم إلى تطبيقها عمليًا، وفهم MVC وCRUD والعلاقات بين الجداول وطريقة تنظيم مشاريع Laravel.
